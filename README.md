## 🚀 Featured projects

### 🔑 [secure-pass-analyzer](https://github.com/noshaeec/secure-pass-analyzer)
A Java 21 Maven CLI that scores password strength using a set of rules, checks passwords against known breaches through the **Have I Been Pwned** API (built-in `HttpClient`, no extra dependencies), and includes a hashing demo.
✅ 53 passing tests

### 🛡️ [eb-security-hardening-lab](https://github.com/noshaeec/eb-security-hardening-lab)

🔧 In progress
